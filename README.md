# homebrew-tap

Homebrew formulae for [pidster](https://github.com/pidster)'s tools.

```bash
brew install pidster/tap/daimon
```

| Formula | What it is |
| --- | --- |
| [daimon](Formula/daimon.rb) | On-device, tool-using AI microharness for macOS, built on Apple's Foundation Models. Apple silicon, macOS 27 or later. Source and docs: [pidster/daimon](https://github.com/pidster/daimon). |

Formulae install prebuilt binaries from each project's GitHub releases; no Xcode or toolchain is needed.
